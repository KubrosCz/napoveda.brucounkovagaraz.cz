# 🧑‍💻 Uživatelské rozhraní

Mobilní aplikace **Bručounkova garáž - Driver** slouží řidičům k plánovaní směn, evidenci vozidel, předávacím protokolům, hlášení závad a jízdám. 

### Přehled rozhraní
Zde ne podiváme na rozhraní aplikace.
#### Ikona Aplikace  
Po nainstalovaní aplikace, se standartně vytvoří ikona v závsilosti na nastavení vašeho operačního systému v telefonu. Níže můžete viděť ikonu v aplikačním menu. <div className="image-row"><img src="/img/aplikace/02_ui/ui_001.png" alt="Řidiči - UI - ikona aplikace]a" width="200px" /></div>  
### Domovská obrazovka
Domovská obrazovka neboli **Přehled** je základní obrazovka, která se vám otevře po každém spuštění aplikace. Máme zde tyto prvky:
- ❶ Ikonka oznámeni → Notifikační centrum - Zde se nachází veškeré příchozí notifikace
- ❷ Profilová fotografie - Pokud není nastavena, aplikace zobrazuje iniciály. Po kliknutí se zobrazí rychlé menu.
- ❸ Nadcházející směna - Zde je pořehled nejbližší nadcházející směny. Pokud není naplánovaná žádná, objeví se jen informce a tlačítko ❹ <kbd>Zobrazit volné směny</kbd> pro zobrazení plánovače směn.
- ❺ <kbd>Moje směny</kbd> - Zobrazí všechny vaše naplánované směny, tak i historii.  
##### Navigační menu
- ❻ <kbd>Domů</kbd> - dostane vás na domovskou obrazovku
- ❼ <kbd>Směny</kbd> - plánovaní směn
- ❽ <kbd>Auto</kbd> - zde nalezete všechny potřebné informace o přiděleném autě stejně jako i historii vozů.
- ❾ <kbd>Více</kbd> - zda nalezneme další položky, které se nám nevešly na navigační menu

### Plánovač směn
V plánovači směn najdeme tyto ovládaci prvky, které jsou zde **navíc** oproti *Domovské obrazovace*
- ❶ Zobrazení legendy kalendáře
- ❷ Přepnutí zobrazení kalendáře
- ❸ Kalendář
- ❹ Filtry pro zobrazení naplánovaných směn.
- ❺ Tlačítko <kbd>Zapsat se na zálohu</kbd>
<div className="image-row"><img src="/img/aplikace/02_ui/ui_004.png" alt="Řidiči - UI - Plánovač směn]" width="200px" /></div>  

### Moje vozidlo
Jak název napovídá, zde najdeme informace o vozidle, které máme přiřazeno na nejbližší směnu  ❶. Zároveň je zde nalezneme tlačítko <kbd>Zobrazit moje protokoly</kbd> ❷, pod kterým najdeme všechny odeslané předávací protokoly, které slouží i jako historie.
