# 🖥️ Webový dispečink

Webová aplikace **Bručounkova garáž** slouží k řízení provozu taxislužby. Náš portál zahrnuje správu vozového parku, správu řidičů, správu směn a správu předávacích protokolů a hlášení závad u vozidel.

   - Protokoly ke schválení.
