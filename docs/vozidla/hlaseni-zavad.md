# ⚠️ Hlášení závad a servis

Pokud se na vozidle během směny projeví jakákoliv závada (např. svítící kontrolka motoru, nezvyklé zvuky při brzdění, defekt pneumatiky), postupujte následovně:

---

## 1. Hlášení v mobilní aplikaci

1. V menu aplikace klepněte na položku **Nahlásit závadu**.
2. Vyberte kategorii problému:
   - 🛑 Brzdy / Podvozek
   - 💡 Osvětlení / Elektroinstalace
   - ⚙️ Motor / Převodovka
   - 🛞 Pneumatiky / Defekt
   - ❄️ Klimatizace / Topení
3. Zadejte stručný popis problému a vložte fotografii (např. kontrolky na palubní desce).
4. Odešlete požadavek na dispečink.

## 2. Kritické závady

:::caution STOP Jízdy
Pokud se rozsvítí **červená kontrolka tlaku oleje nebo brzd**, okamžitě bezpečně zastavte vozidlo, vypněte motor a neprodleně telefonicky kontaktujte dispečink.
:::
